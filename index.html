Sobre este proyecto

Este es un ejemplo clásico de desarrollo web donde la estructura y el diseño viven en archivos independientes. Esto permite que el código sea mucho más limpio, ordenado y fácil de mantener a medida que el proyecto crece.

Ahora puedes editar los textos aquí en el HTML sin alterar los colores o fuentes, los cuales se controlan exclusivamente desde el archivo de diseño.
